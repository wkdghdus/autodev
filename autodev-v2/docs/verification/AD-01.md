## Changes and effects

AD-01 adds:

- immutable versioned contract models for projects, execution indexes,
  installation bindings, grants, receipts, operation journals, command results,
  readiness state, and migration previews;
- strict YAML 1.2 ingestion with a 1 MiB limit and rejection of malformed input,
  duplicate keys, tags, anchors, aliases, multiple documents, non-string keys,
  unknown fields, unsupported versions, coercion, and repository-root escapes;
- pure permission intersection, installation identity comparison, orthogonal
  readiness evaluation, and preview-only V1 migration logic;
- configured, draft, provider-name, empty-index, approved-index, and invalid-graph
  fixtures under `fixtures/ad01/`; and
- focused tests for AD-01 acceptance criteria and faults while preserving every
  AD-00 placeholder command.

Observed side effects were limited to repository-local ignored Python bytecode
and reads of explicit fixture/temporary-repository content. The migration API
returns an immutable draft plan and has no apply or write operation.
